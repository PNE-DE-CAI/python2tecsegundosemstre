Exercício 01

📝 Média de 3 Entregas

Escreva um código que calcule a média de 3 notas (a, b, c) digitadas pelo usuário.

nota1 = float(input("Digite a primeira nota: "))
nota2 = float(input("Digite a segunda nota: "))
nota3 = float(input("Digite a terceira nota: "))
media = (nota1 + nota2 + nota3) / 3
print(f"A média é {media}")
Estruturas de Decisão

⚖️ if / else

A estrutura condicional permite executar ações diferentes com base em uma condição.

if (idade >= 18):
    print("Você é maior de idade.")
else:
    print("Você é menor de idade.")
Importante: A indentação (recuo) define o bloco de código que pertence ao if ou else.
Exercício 02

✅ Aprovado ou Reprovado?

Adicione condicionais ao exercício anterior para verificar se o estudante foi aprovado (média ≥ 7) ou reprovado.

media = (nota1 + nota2 + nota3) / 3
if media >= 7:
    print("Aprovado!")
else:
    print("Reprovado.")

🤖 IA ajuda a aprender ou atrapalha?

✅ Boas práticas com IA

  • Pedir para explicar o código
  • Pedir para prever o resultado
  • Pedir para modificar ou corrigir
  • Propor problemas semelhantes

❌ Riscos

  • Pedir que resolva tudo sem esforço
  • Copiar sem entender
  • Não testar ou validar
Estruturas de Repetição

🔄 For e Listas

O for percorre uma sequência (lista, range, string) item por item.

Range – contador

for numero in range(1, 6):
    print(f"Tentativa {numero}")

Lista de números

notas = [7.2, 7.6, 8.0, 9.5]
for nota in notas:
    print(f"Nova nota: {nota + 0.5}")

Lista de strings

nomes = ["Ana", "Bruno", "Carlos"]
for nome in nomes:
    print(nome)
Exercício 03

📥 10 Entregas com For

Use um laço for para solicitar 10 notas e calcular a média.

soma = 0
for i in range(1, 11):
    nota = float(input(f"Nota {i}: "))
    soma += nota
media = soma / 10
print(f"Média: {media:.2f}")

Mediação

🧠 O papel do professor na era da IA

Antes da IA

  • Memorizar sintaxe
  • Reproduzir códigos
  • Seguir exemplos

Depois da IA

  • Compreender problemas
  • Analisar soluções
  • Interpretar códigos
  • Fazer boas perguntas
O papel do professor não diminui. Ele se torna ainda mais importante como mediador do pensamento.
